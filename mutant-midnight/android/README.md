# Mutant Midnight — Android APK

Native Android retro mutant survival shooter. This is an Android Studio/Gradle project, not a browser game.

## Controls
- Bluetooth / USB controller: left stick moves; right stick aims; A, R1 or R2 fires.
- Keyboard/mouse: WASD or arrow keys move; mouse aims; Space fires.
- Touch: drag on the lower-left area to move; tap/hold elsewhere to aim and fire.

## Build
Open this folder in Android Studio, let it download the Android SDK dependencies, then select **Build > Build APK(s)**. The debug APK is created at `app/build/outputs/apk/debug/app-debug.apk`.
